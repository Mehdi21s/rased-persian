# ربات ترجمه و بازنشر عربی به فارسی

## امکانات
- خواندن پست‌های جدید از `@rasedal3ado138e`
- استفاده از متد رسمی `messages.translateText` تلگرام برای ترجمه به فارسی (با حساب کاربری Telethon؛ نه Bot API)
- بازنشر متن، عکس، ویدیو و آلبوم در `@rasedpersian`
- پنل خصوصی در ربات مدیریت: `/start`، `/settag متن`، `/tag`، `/status`
- صفحه سلامت ساده برای سرویس میزبانی

## متغیرهای لازم
`API_ID`, `API_HASH`, `SESSION_STRING`, `BOT_TOKEN`, `ADMIN_ID` و در صورت نیاز `SOURCE_CHANNEL`, `TARGET_CHANNEL`, `POST_TAG`.

- `SESSION_STRING`: نشست حساب کاربری تلگرام که Premium روی همان حساب فعال است. این مقدار را محرمانه نگه دار.
- `BOT_TOKEN`: توکن ربات جداگانه‌ای که با BotFather ساخته‌ای و برای پنل مدیریتی است.
- `ADMIN_ID`: شناسه عددی حسابی که تنها اجازه استفاده از پنل را دارد.
- حساب کاربری نشست باید به کانال منبع دسترسی داشته باشد و اجازه انتشار در کانال مقصد را داشته باشد.

## اجرای محلی
```bash
pip install -r requirements.txt
python main.py
```

## استقرار رایگان در Render
1. این پوشه را در یک مخزن خصوصی GitHub قرار بده.
2. در Render گزینه New > Blueprint را انتخاب و مخزن را وصل کن.
3. متغیرهای محیطی بالا را در داشبورد Render وارد کن.
4. بعد از Deploy، لاگ‌ها را بررسی کن و دنبال `STARTUP_MARKER=ARABIC_TO_PERSIAN_TELEGRAM_TRANSLATOR_V1` بگرد.

**محدودیت مهم:** سرویس رایگان Render ممکن است بعد از مدتی بی‌ترافیکی به خواب برود و فایل‌های محلی آن ماندگار نیستند. بنابراین این گزینه برای تست رایگان مناسب است، اما پایداری ۲۴/۷ تضمین نمی‌شود و تنظیم تگ ذخیره‌شده در فایل ممکن است بعد از بازسازی/تعویض نمونه از بین برود.

## نکات
- متد ترجمه رسمی تلگرام در API فقط برای حساب کاربری قابل استفاده است؛ به همین دلیل ترجمه با نشست کاربر انجام می‌شود، درحالی‌که ربات Bot API فقط پنل را فراهم می‌کند.
- اگر تلگرام ترجمه را به‌دلیل سهمیه یا خطای موقت رد کند، آن پست بازنشر نمی‌شود تا متن عربی به‌اشتباه به‌عنوان ترجمه فارسی منتشر نشود. خطا در لاگ ثبت می‌شود.
- کپشن‌های طولانی برای جلوگیری از خطای محدودیت کپشن، بعد از رسانه به‌صورت پیام متنی جداگانه منتشر می‌شوند.
- این کد از نظر نحوی بررسی می‌شود، اما پیش از استفاده واقعی باید با حساب و کانال‌های خودت آزمایش شود.
